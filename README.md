# WhatsApp Data -- removed from the catalog

This repository used to profile a RapidAPI marketplace listing (rapidapi.com/convapi-convapi-default/api/whatsapp-data10, served from whatsapp-data10.p.rapidapi.com)
under the name "WhatsApp Data".

It was removed on 2026-09-23 as a catalog-hygiene decision by API Evangelist (roadmap#621). Nobody asked.
A marketplace listing is not the provider's own API, and API Evangelist and APIs.io do not index RapidAPI
listings.

The slug is on the delisting registry (api-search/network/_data/delisted.yml), and RapidAPI-hosted listings
are refused at intake, so harvests will not re-add it. Questions: info@apis.io.
